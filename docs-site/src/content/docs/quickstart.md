# 快速开始

## 基本使用流程

### 1. 新建小说项目

启动应用后新建项目，指定项目名称、题材、目标字数。

### 2. 导入或生成大纲

导入已有大纲，或通过 AI 生成。也可从拆书库提取文风作为风格约束。

### 3. 配置模型

在设置中配置 LLM API 地址和密钥。可设置「默认模型」统筹后台任务。

内置预设支持 DeepSeek、Google、智谱等，多选启用；也支持自定义模型，标签式批量管理与批量测试。

:::tip[本地模型]
支持 Ollama 等 OpenAI 兼容接口，可完全离线使用本地模型（数据本地优先架构，LLM 调用除外）。
:::

### 4. 开始写作

在 AI 对话区输入写作指令，例如"继续写第 30 章"。

支持的生成模式：

- **续写**：接着上文往下写
- **扩写**：对已有内容扩展
- **改写**：重写某段
- **润色**：优化表达

### 5. 审阅草稿

AI 生成的章节默认为**草稿状态**。草稿支持预览、编辑、重新生成、审稿。

草稿机制是写作安全边界——**只有用户确认后才会保存为正式章节并触发记忆摄取，草稿不会污染正式记忆库**。

### 6. 确认保存

满意后保存为正式章节，系统自动摄取记忆：提取章节摘要、出场人物/地点/组织/物品、关键事件、人物关系变化、伏笔推进、时间线事件、图谱节点与关系边。

### 7. 查看图谱与审查

- 在**图谱视图**查看人物关系网络
- 在**审查中心**查看六维评分与角色命中报告

## 长篇写作常见问题对照

| 问题 | niko-hub 的解决方案 |
|------|----------|
| AI 写到后期遗忘前文 | 章节快照 + 最近章节正文片段 + 混合检索 + 上下文包自动组装 |
| 人物性格前后不一致 | 角色状态追踪 + 灵魂绑定 + 人设一致性审查 + 角色命中记忆库检查 |
| 时间线混乱 | 结构化时间线 + 连贯性检查 + 时间线冲突报警 |
| 伏笔丢失或错乱 | 伏笔追踪器 + 债务评分 + 自动检测未回收伏笔 |
| 角色知道不该知道的信息 | 角色认知系统（knows / does_not_know） |
| AI 生成错误内容污染后续 | 草稿/正式章节分离 + 人工确认后才入库 |
| 生成内容 AI 味重 | 去AI化改写 + 项目灵魂风格控制 + 作品文风约束 |
| 长章节超出模型上下文 | 发送前按模型真实输入上限自动裁剪并重试 |
