# ⚙️ 设置

设置页（`activeView: settings`）是 QMAI 的统一配置中心：左侧为分类导航，右侧为当前分类的配置表单。所有修改先停留在草稿态，点击底部「保存」按钮后才统一写入本地配置并同步到内存状态，避免误触即改。

## 主路径

- 点击侧边栏「设置」入口进入设置页；其他页面的帮助入口也支持深链直达指定分类。
- 在左侧分类导航中选择配置类别，共 14 类：
  - 大语言/LLM 模型：提供商、API Key、模型、上下文大小、推理模式、本地 CLI 隔离等
  - 重排/Reranker 模型：重排提供商与候选数（3-30）
  - 向量检索/Embedding 模型：端点、模型、输出维度、分块大小与重叠
  - 网络：代理开关、代理地址、本地地址绕过
  - 界面：界面语言、字体缩放
  - 小说：小说模式相关配置
  - 软件使用说明、技能库、MCP 工具、维护、数据管理、反馈、联系与支持、更新日志
- 修改表单项（草稿态，底部会提示尚有未保存的更改）。
- 点击底部「保存」：全部分类草稿一次性落盘，按钮短暂显示「已保存」。

## 常用配置说明

- LLM 分类内置常用云端提供商预设，也支持本地 Ollama 与自定义端点（可切换 API 模式）；Azure 提供商可配置 API 版本与模型家族。
- 向量检索分类可开启或关闭 Embedding，并按需调整分块与重叠字符数。
- 定时导入可指定监听目录与扫描间隔（1-1440 分钟），开启后按周期自动导入新资料。

## 保存行为

- 保存时依次写入 LLM、Embedding、重排序、多模态、代理、定时导入、资料目录监听、修订反馈窗口、小说配置、输出语言、历史消息条数、字体缩放等配置。
- 代理配置保存后会即时应用到运行环境（无需重启），应用结果通过 toast 提示成功或失败。
- 资料目录监听与定时导入会按新配置立即启动或停止后台同步。
- 界面语言在保存后立即切换。

## 状态与限制

- 空态：分类无配置项时显示空表单；「软件使用说明」「更新日志」等分类为纯信息展示，无保存项。
- 加载/错误：页面懒加载时显示「加载中...」；切换项目后自动重新加载该项目级配置（资料目录监听、小说配置、重排序配置）；代理环境变量应用失败会弹出 toast 错误，已保存的配置在重启后仍会生效。
- 已知限制：设置项长表单暂不支持分组、分页与筛选（未交付 · P1-2）。
