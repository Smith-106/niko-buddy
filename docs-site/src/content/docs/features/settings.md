# ⚙️ 设置

设置页（`activeView: settings`）是 Niko Buddy 的统一配置中心：左侧按 **5 个分组、18 个分类**组织导航，右侧展示当前分类的配置表单或信息面板。配置落盘采用**三域分存（模型域 / 存储域 / 界面域）**与**三种保存模式（草稿保存 / 自动保存 / 纯展示）**，各域互不串写，避免跨分类误覆盖。

## 主路径

- **有项目态**：点击侧边栏「设置」入口进入完整设置页；其他页面的帮助入口也支持深链直达指定分类。
- **无项目态（欢迎屏）**：在未打开项目时点击新建项目弹窗中的「模型服务 → 立即配置」，会弹出**独立模型配置对话框**（直接内嵌大语言/LLM 模型提供商配置），无需先创建项目或进入完整设置页即可配置 API Key 与默认模型。
- 在左侧分类导航中选择配置类别（共 **18 类 / 5 分组**）：
  - **模型与工具**（7 类）：
    - 大语言/LLM模型：提供商预设、API Key、模型、上下文大小、推理模式、本地 CLI 隔离、HTTP 超时等（草稿保存 · 模型域）
    - 重排/Reranker模型：重排提供商与候选数（3-30）（草稿保存 · 模型域）
    - 向量检索/Embedding模型：端点、模型、输出维度、分块大小与重叠、离线模式开关（草稿保存 · 模型域）
    - 图片描述：多模态开关、复用主 LLM 或独立配置、并发数（草稿保存 · 模型域）
    - 网页搜索：联网检索配置（自动保存）
    - MCP 工具：配置本应用连接的外部 MCP 服务（自动保存）
    - 外部控制（应用内 MCP）：允许外部 Agent（如 Claude Code / PI）经仅回环地址与 Bearer 鉴权接入本应用，默认关闭、按只读基线与逐会话权限档控制写操作，token 存入系统凭据库（纯展示/即时切换，无草稿态）
  - **写作**（3 类）：
    - 小说：目标字数、写前门控模式、审稿模型、场景切分、工作流强度、对话历史条数、修订反馈窗口、任务提示词与技能等（草稿保存 · 存储域）
    - AI 回复语言：设置 AI 输出语言（草稿保存 · 界面域）
    - 技能库：浏览与管理内置/自定义写作技能（纯展示/即时操作）
  - **应用**（2 类）：
    - 界面：界面语言、字体缩放（草稿保存 · 界面域）
    - 网络：代理开关、代理地址、本地地址绕过（草稿保存 · 存储域）
  - **数据**（2 类）：
    - 数据管理：全量数据导出/导入与云同步备份设置（纯展示/即时操作）
    - 维护：项目索引与本地维护操作（纯展示/即时操作）
  - **帮助与支持**（4 类）：
    - 软件使用说明、反馈、联系与支持、更新日志（含应用内检查更新与下载安装）（纯展示）

## 任务提示词与技能（v2.9.0）

「小说 → 任务提示词与技能」区块支持按任务自定义两类注入：

- **追加提示词**：拼接到对应任务提示词尾部（正文写作 / 大纲生成 / 六维审查 / 章节摘要 / 设定提取五类），用于注入个人风格约束、题材偏好等。
- **技能名单覆盖**：填写技能库中的技能名称（逗号分隔），非空时覆盖内置技能选择（正文/大纲/审查三组意图生效，经技能库存在性校验，缺失名单进入诊断面）。

空配置与旧行为逐字节一致（三层等价设计）；审查门控（确定性引擎 + P0 优先级）不受追加提示词影响。

## Webhook 通知（v2.7.8，64 号实施）

- 事件：run.stalled（守护边沿一次）/ run.completed / chapter.accepted / translation.finalized
- `buildSignedWebhookRequest`：HMAC-SHA256 签名（`sha256=<hex>`）+ 事件头；回调验签 `verifyWebhookSignature`
- 密钥仅函数参数，不入 status.json / telemetry / 日志（CWE-532 纪律）；payload 禁正文/绝对路径/token
- 通知派发走注入式 `NotifyTransport`（引擎层零 HTTP 依赖）；`shouldNotify` 边沿判定保证 stalled 只通知一次

## 常用配置说明

- **大语言/LLM模型**：内置常用云端提供商预设，也支持本地 Ollama、本地 CLI（Claude Code / Codex / Cursor）与自定义端点（可切换 API 模式）；Azure 提供商可配置 API 版本与模型家族。
- **向量检索/Embedding模型**：可开启或关闭 Embedding 与离线模式，并按需调整分块与重叠字符数。
- **外部控制（应用内 MCP）**：与「MCP 工具」方向相反——「MCP 工具」是本应用连接外部工具，「外部控制」是外部 Agent 连入本应用。默认不启动；开启后仅监听本地回环地址，写操作须经权限域与逐会话授权（直写正文需逐会话 `full` 授权）。
- **数据管理与同步备份**：在同一分类下提供一键导出/导入项目数据以及同步备份（含 GitHub 私有仓目标）的开关与间隔配置。

## 保存模式与三域分存

设置页按分类采用**三种保存模式**，底部保存栏随当前分类动态切换：

- **草稿保存（`draft`）**：适用大语言/LLM模型、重排/Reranker模型、向量检索/Embedding模型、图片描述、小说、AI 回复语言、界面、网络 8 个分类。改动先留在草稿态，点击底部「保存」时**仅保存当前分类所属域**，按钮短暂显示「已保存」；若其他域存在未保存改动，底部会显式提醒前往对应页面保存。
  - **模型域（模型与检索）**：写入 LLM、Embedding、重排序与图片描述（多模态）配置。
  - **存储域（网络与写作）**：写入代理网络、资料目录监听、定时导入、修订反馈窗口、小说配置、工作流强度与历史消息条数；代理配置保存后会即时应用到运行环境，资料目录监听与定时导入按新配置即时启停。
  - **界面域（界面）**：写入 AI 回复语言、界面语言与字体缩放；界面语言保存后立即切换。
- **自动保存（`auto`）**：适用网页搜索、MCP 工具 2 个分类。表单改动后立即持久化，底部只显示自动保存提示，不显示保存按钮。
- **纯展示 / 即时操作（`none`）**：适用外部控制、技能库、数据管理、维护、软件使用说明、反馈、联系与支持、更新日志 8 个分类。底部不显示保存栏；操作类开关（如外部控制启停）直接作用于运行态或系统凭据库，不存在待保存草稿。

## 状态与限制

- **空态与信息页**：部分分类为只读信息展示或工具操作区，不含表单草稿项。
- **加载与项目切换**：页面懒加载时显示「加载中...」；切换项目后自动重新加载项目级配置（资料目录监听、小说配置、重排序配置），代理环境变量应用失败会弹出 toast 提示且已保存配置在重启后仍生效。
- **长表单导航**：左侧已提供 5 分组 / 18 分类导航，但单个长配置页内部暂不支持二次分页或关键词筛选。
