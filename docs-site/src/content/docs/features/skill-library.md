# 🧩 技能库

技能库（`activeView: skillLibrary / writingSkillLibrary / skillFavorites` 三值合挂同一个统一视图）集中管理两类技能：「去AI味技能」与「写作 Skill」，并提供跨项目的「收藏」视图。顶部 Tab 负责三个视图间的切换，左侧栏提供统一检索与分类过滤，右侧为技能编辑区。

## 主路径

- 通过顶部 Tab 切换三个视图：**去AI味技能**（重写/文风类规则）、**写作 Skill**（三翻四抖、章节计划、伏笔检查等写作规则）、**收藏**（跨项目星标技能）。
- 左侧栏统一检索两类技能：支持按名称、说明、规则内容搜索，并按分类过滤（全部/写作/去AI味/审稿/输出/知识）。
- 点击侧栏条目会自动跳到其所属 Tab 并选中编辑；条目带「写作/去AI味」类型徽标，未填写说明的技能显示占位提示。
- 写作 Skill 支持自定义分类管理，可在编辑区新建分类。
- 新建：去AI味 Tab 提供「新建技能」，写作 Tab 提供「新建 Skill」，均以空白模板创建并进入编辑。
- 导入：两种技能均支持从文件导入（JSON/md/txt），详见下方导入说明。
- 编辑完成后保存，配置写入当前项目并提示「写作 Skill 已保存」或「去AI味技能已保存」。

## 收藏视图

- 在技能条目上点击星标收藏或取消收藏，收藏记录携带来源项目信息，可跨项目使用。
- 收藏列表按收藏时间倒序展示，支持按名称与说明搜索。
- 支持一键「复制到当前项目」：当前项目已有的技能（含内置技能）会显示「已在当前项目」、无需复制；复制到已存在同名技能的项目时会提示复制失败。
- 收藏卡片会标注技能库类型与来源（内置/项目/上传/链接等）及收藏时间。
- 删除收藏前会弹出确认，删除成功后有 toast 提示。

## 导入说明

- 去AI味技能：JSON 文件需包含名称与内容字段；md/txt 文件会解析 frontmatter 中的 name/description，缺省时以文件名命名；导入后自动设为默认技能。
- 写作 Skill：JSON 文件按标准 Skill 结构解析（格式不正确会提示导入失败）；md/txt 文件以文件名作为技能名导入。
- 文件内容无效时会提示不是有效的技能文件，不会写入损坏数据。

## 状态与限制

- 空态：去AI味列表显示「暂无技能。」；写作 Skill 列表提示可新建「三翻四抖」「章节计划」「伏笔检查」等规则；收藏页显示「暂无收藏的技能」并引导点击星标收藏；搜索无结果时显示「没有匹配的技能」/「没有匹配的收藏」。
- 加载/错误：收藏页在数据加载完成前显示「加载中...」；技能库侧栏加载失败会提示「技能库加载失败」；导入文件格式不正确时给出导入失败提示。
- 防丢失：编辑中有未保存修改时，切换、新建或导入会先弹出丢弃确认，避免草稿意外丢失。
- 内置技能与项目技能均可星标收藏。
- 已知限制：技能长列表暂不支持分页（未交付 · P1-2，侧栏已提供搜索与分类过滤缓解）。
