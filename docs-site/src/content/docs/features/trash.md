# 🗑️ 回收站

回收站（`activeView: trash`）承接从写作工作区删除的章节、大纲、页面与历史记录，默认保留 30 天，到期自动清理。误删的内容在保留期内可随时预览、恢复或彻底清除，为写作过程提供安全的兜底。

所有回收数据按项目存放，切换项目后看到的回收项只属于当前项目。

## 主路径

- 点击侧边栏「回收站」入口进入；侧栏顶部显示保留策略（内容默认保留 30 天）与当前回收项数量徽标。
- 回收项按删除时间倒序排列，类型标记为章节、大纲、页面或历史记录。
- 点击列表中的回收项，预览区会显示「已删除项目」信息（名称、类型、原路径）与内容预览，帮助确认是否是要找回的内容。
- 点击条目上的恢复按钮（↺）：文件恢复到原位置；如原位置已有同名文件，会自动改名恢复。
- 恢复章节/大纲/页面后会自动跳回写作工作区并选中新文件，同时刷新文件树与图谱等数据视图。
- 恢复历史记录类项目时只还原数据本身，不会切换视图。
- 需要彻底清除时，点击条目上的删除按钮永久删除单项；或点击「清空回收站」一次性清空全部回收项（清空过程中按钮显示「清理中…」并禁用其他操作）。
- 删除或恢复操作完成后列表即时刷新，数量徽标同步更新。
- 每次进入回收站时会自动清理已超过保留期的过期项目。

## 适用范围

- 章节与大纲：恢复后回到原路径，可继续编辑。
- 页面/文件：恢复到原位置，冲突时自动改名。
- 历史记录：来自章节/大纲的修订历史删除，仅支持预览与彻底删除，恢复操作不适用。

## 与写作工作区的关系

- 回收站视图与写作视图（wiki）复用同一工作区布局，差异仅在侧栏内容与预览对象。
- 因此恢复成功后可以无缝跳回写作视图并定位到恢复的文件，无需手动查找。

## 状态与限制

- 空态：回收站为空或未选中回收项时，列表显示「回收站为空」。
- 加载/错误：列表加载时显示「正在加载回收站…」；读取回收项内容、恢复或删除失败时在控制台记录错误，列表保持可用，可重试操作。
- 数据一致性：恢复成功后图谱、记忆中心等数据视图会随数据版本刷新保持同步。
- 注意：清空回收站与单项永久删除会立即生效且不可撤销，执行前请确认不再需要这些内容。
- 已知限制：删除历史暂不支持分页浏览（未交付 · P2）。
