# 人物幽灵创伤外化与愿望-动机-行动链（P2 Quality）

## 何时使用
当创建主角/核心配角人物卡、解决人物纸片化或工具人化、安排角色首次登场、或校验人物弧线驱动力时调用本技能。直接对齐 `niko-buddy` T28 `craft.mckee-ghost-wound`、`craft.wish-motive-action` 与 `craft.significant-details`。

## 一、幽灵/旧伤四格驱动链（Ghost / Wound）
区分「背景故事」与「幽灵（Ghost）」：背景故事只是静态履历，**幽灵是至今仍在暗中扭曲角色判断的未愈创伤**。设计核心角色必须填满以下四格：
1. **源头创伤（Ghost）**：过去发生过的那件不可逆事件（背叛、无力救人、尊严践踏、误判致祸）。
2. **错位信念（Lie / Defense）**：创伤逼出的错误生存法则（如「只要不依赖任何人就不会再失去」「弱者活该被淘汰」）。
3. **外化条件反射（Behavioral Tell）**：禁止用旁白解释创伤！必须转译为日常高频可见的动作、禁忌、反应延迟或过度补偿（如进门永远背靠墙数出口、一提某词立刻岔开话题）。
4. **揭晓与触碰节点（Reveal Beat）**：在卷纲中锁定至少 1 处被迫正面触碰旧伤的高压场景，避免 `ghost-unrevealed`（设了旧伤却全书没派上用场）。

## 二、愿望—动机—行动链（Wish → Motive → Action）
确保主角和主要配角每场戏都有主动推力，避免被动沦为摄像头：
- **表层愿望（Want）**：角色当前明确想拿到什么具体利益/目标（可衡量输赢）。
- **深层需要（Need）**：角色自己尚未意识到的灵魂缺口（通常直指旧伤的对立面）。
- **行动与代价**：每章核心动作必须直接服务于 `Want`，并在推进途中不断撞击 `Need`；角色面对的不是“好与坏”的廉价选择，而是“保住旧防御 vs 付出代价蜕变”的真实两难。
- **人物关系三角**：用「主角—核心盟友/羁绊—主敌/镜像对手」搭建三角张力，让配角不仅服务剧情，还反向照见主角的盲区。

## 三、显著细节书签法（单角色 ≤ 2 个硬上限）
对齐 T28 `craft.significant-detail`：
1. **严禁外貌清单**：禁止角色出场时从发色、眉眼、衣着到身高鞋码逐项扫描。
2. **最多 2 个独立书签**：为每个重要角色只挑 **1–2 个**能直接折射其阶层、职业、性格或旧伤的标志性细节（一个动作癖好、一件随身旧物、或一处反差体貌特征）。
3. **复现变奏**：让这 1–2 个显著细节在全书不同阶段反复出现，但随着处境变化改变含义（如起初擦拭怀表代表克制体面，崩溃时表壳被捏出凹痕代表防线失守）。

## 四、验收清单
- [ ] 核心角色均具备「创伤 → 错位信念 → 外化行为 → 揭晓节点」四格卡，非纯履历表。
- [ ] 角色在当前章节的行动有清晰的 `Want → Action → 代价` 链条，行为基准与人设一致。
- [ ] 单角色标志性显著细节严格 **≤ 2 个**，出场无泛化外貌清单。
