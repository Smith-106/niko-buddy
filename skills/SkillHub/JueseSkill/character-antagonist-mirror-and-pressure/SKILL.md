# 角色设定 · 高魅力宿敌镜像与四级压迫反派系统

## 何时使用与适配题材
- **最佳适配**：一切长篇商业小说、玄幻仙侠、悬疑智斗、历史权谋、女频宅斗与科幻史诗（主角的上限由反派的格调决定）。

## 一、好反派的三条铁律
1. **反派自认是自己故事里的主角**：他必须有清晰且在其立场上完全合理的终极愿望（复仇、维持秩序、拯救族人、追寻真理、避免更大灾难），只是他愿意付出的代价触碰了主角的底线。
2. **暗面镜像结构**：最高级的宿敌与主角经历过**相似的创伤或诱惑**，但在岔路口做出了相反选择——主角赢过反派，本质上是主角战胜了自己内心最危险的另一种可能。
3. **战力/智商/资源至少一项压倒性占优**：让主角处在麦基所说的「下风狗位置」，迫使主角穷尽智慧、盟友与代价才能险胜。

## 二、四级压迫梯度（长篇反派排兵布阵）
避免每卷重复同一个模板的小反派，按卷递进升级压迫形态：
- **L1 贴身恶狗 / 利益截胡者**（开篇 1–30 章）：具体可恨、门槛低、能快速兑现首轮打脸爽感，背后牵出更高层阴影。
- **L2 镜像天才 / 同辈宿敌**（前中期）：资源与天赋压过主角，和主角争夺同一晋升通道/核心资源，彼此数次交锋互有胜负。
- **L3 阵营掌权者 / 秩序既得利益者**（中后期）：不靠单挑靠规则、律法、经济与舆论碾压主角，逼主角从「个人武力」升维到「建势借力」。
- **L4 理念宿敌 / 体系本身 / 不可名状终局危机**（大结局）：与主角进行终极价值对决，胜负决定世界新秩序。

## 三、反派「不降智」五项自检
1. 反派是否只在自己掌握的情报范围内做理性决策？（不靠作者安排强行送死）
2. 反派发现主角构成威胁时，是否先试探、再派合适手下、发现异常立刻升级规格？（拒绝葫芦娃救爷爷式逐级送经验）
3. 反派有没有自己的弱点、软肋或内部掣肘（如派系内斗、寿元将近、必须遵守的契约），使主角的翻盘合情合理？
4. 反派有没有让读者印象深刻的个人癖好、金句或体面瞬间？
5. 反派退场时是否保留了性格一贯性（至死不悔、冷笑认输或临死反咬埋下后患），而非突然痛哭流涕忏悔？

## 绝对禁止项
- 禁止反派在占绝对优势时发表冗长演讲解释全部计划直到被翻盘。
- 禁止把所有女性/底层反派一律写成嫉妒发疯的扁平脸谱。
- 禁止在最终正文中解释上述层级模型。
