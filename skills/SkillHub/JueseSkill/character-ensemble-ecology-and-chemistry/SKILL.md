# 角色设定 · 群像卡司生态位与化学反应矩阵

## 何时使用与适配题材
- **最佳适配**：多线群像长篇、冒险小队、宗门/学院/朝堂群戏、武侠江湖、无限流团队副本、多势力博弈。

## 一、六大卡司生态位（拒绝功能重复）
设计核心常驻阵容（建议 4–6 人）时，每人须占据**不可替代的叙事生态位**，同队禁止塞入两个功能重叠的「同质高冷军师」或「同质傻白甜」：

| 生态位 | 叙事职责 | 与主角的天然张力 |
|---|---|---|
| **1. 核心驱动者（主角）** | 承担核心命题抉择、推进主线愿望 | 自身欲望（Want）与内在需要（Need）拉扯 |
| **2. 镜像宿敌 / 暗面对照** | 同一处境下选择另一条极端道路的「另一个自己」 | 逼主角直面自身信念漏洞 |
| **3. 情感锚点 / 人性底座** | 提醒主角为何而战、拉住主角不彻底堕落 | 保护成本与主线野心直接冲突 |
| **4. 理性刹车 / 异议者** | 专门质疑主角冲动决策、提供现实代价视角 | 价值观碰撞，防止主角团一言堂 |
| **5. 混乱变量 / 破局催化剂** | 规则之外的不稳定因素，打破僵局或引爆意外 | 不可控性制造危机与喜剧/悬疑变数 |
| **6. 视角桥梁 / 时代切片** | 代表底层、局外人或对立阵营的眼光，折射主角成长与世界全貌 | 信息差与立场转变带来强烈戏剧感 |

## 二、关系化学反应「三角张力法」
- 严禁把所有配角做成「只围绕主角转的辐射状卫星」。
- 任意挑出两名重要配角（B 与 C），必须为他们建立**独立于主角之外的私人关系**：旧债、理念世仇、秘密交易、单向仰慕或共同隐瞒主角的秘密。
- **群戏黄金法则**：一场超过 3 人的重要对手戏，现场必须同时运行 **≥ 2 组不同议程**（例如 A 想套情报，B 想保住某人，C 趁机转移赃物），让台词一石二鸟。

## 三、配角去工具人三问
每次让核心配角出场前自检：
1. 主角不在这个场景时，这个配角今天本来在忙什么？（独立生活轨迹）
2. 他这次帮主角或挡主角，图的究竟是什么私心/信念？（独立动机）
3. 这一卷结束后，他自己的命运或立场会发生什么不可逆变化？（独立微弧光）

## 绝对禁止项
- 禁止用「全员无脑吹捧主角 / 全员瞬间倒贴」替代真实关系推进。
- 禁止单场群戏平均分配台词变成点名发言（须有主焦点 1–2 人，其余以动作反应陪衬）。
- 禁止在最终正文中解释本矩阵术语。
