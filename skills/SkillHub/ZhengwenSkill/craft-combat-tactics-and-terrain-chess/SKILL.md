# 大写作手法 · 高潮战斗调度与地形博弈棋局

## 何时使用与适配题材
- **最佳适配**：一切包含冷兵器拼杀、法术神通对决、都市异能巷战、枪战伏击与跨阶绝境反杀的动作高潮章节。

## 一、好战斗不是招式表，而是「动态象棋」
每一场重头战斗拆解成 **5 个变化筹码** 推进，绝不原地对轰：
1. **空间距离与站位**：长兵器占中远距离、短刃/近体术死贴内圈、法师/狙击手死守高地视野——每一次移动都在抢占或失去安全距离。
2. **地形与环境武器化**：狭巷、雨夜泥地、晃动船板、燃烧仓库、浓雾拐角、能遮挡神识的金属墙——**让环境参与进攻与遮蔽**。
3. **体力 / 灵力 / 冷却倒计时**：写清主角护盾还能撑几息、左手已麻木握不住剑、敌人大招蓄力前肩胛骨的预兆——倒计时让每一秒都让人屏息。
4. **招式逻辑与代价交换**：没有无敌神功，大威力绝技往往伴随着**重心暴露、视野受阻或真气回气空档**，高手都在用小伤换对方这个致命空档。
5. **心理诈术与破绽钓鱼**：故意连续出三次同一路假招养成敌人肌肉记忆，第四次在敌人习惯性格挡瞬间骤变杀招。

## 二、高潮战斗「三段节奏」
- **试探交锋（测深浅）**：2–3 拍快切摸清对手速度、力量、武器特质与保命习惯，吃点小亏却拿回关键情报。
- **绞杀绝境（底牌逼出）**：被对手硬实力或同伴合围压到退路断绝、伤痛加剧，主角被迫亮出半张风险极高的底牌或冒险利用地形险中求生。
- **一锤定音（瞬间静默）**：反杀成立瞬间砍成冷冽特写短句（兵器错身声、血线溅起、尘埃落地），战后立刻描写喘息与伤痛余震，切忌打完直接瞬回满血聊天。

## 绝对禁止项
- 禁止堆砌空洞大招名词与公里级光柱特效，读者不知道双方到底在打什么、为什么赢。
- 禁止「主角突然顿悟突破 / 临时想起师父曾教过神功」这种机械降神翻盘。
- 禁止在最终正文中输出战术术语表。
