# 大写作手法 · 场景节拍推进与视角纪律

> 理论溯源：WeKnora `写作技法库`（罗伯特·麦基《故事》《对白》、詹姆斯·斯科特·贝尔《冲突与悬念》、Renni Browne《Self-Editing for Fiction Writers》）。

## 何时使用与适配阶段
- **核心场景**：长篇/短篇正文起草、卡文排查、或修订「场景像流水账/对话干瘪反复/视角乱跳」的草稿。

## 一、最小推进单元：行动—反应节拍（Beat）与价值翻转
- **节拍定义**：一个角色带着**潜文本意图**做出动作或出言试探，触发对方或环境的**即时反应**，构成 1 个节拍。
- **防车轱辘铁律**：如果人物在 3 句对白/动作后仍在用同一种策略表达同一意图，说明节拍已死，**必须立即更换策略**（例如从示弱请求 → 拿利益交换 → 隐晦施压 → 掀桌离席）。
- **每场必有价值负荷翻转**：进场前与离场时，场景核心价值（安全/危险、信任/怀疑、优势/劣势、获知/迷茫）**必须完成一次不可逆偏移**（正转负、负转更负或带代价的负转正）。没有价值变化与因果后果的场景直接删并。

## 二、Scene × Sequel 呼吸控制与四级悬念
1. **行动场景（Scene）**：目标（Goal，必须高赌注）→ 阻碍与冲突（Conflict，对手或环境阻挠）→ 挫败或意外转折（Disaster，通常以「是，但…… / 不，并且更糟……」收束，推高后续张力）。
2. **续场（Sequel，视篇幅克制使用）**：情感震荡（Reaction）→ 盘算处境（Dilemma）→ 做出新决定（Decision，直接触发下一场目标）。快节奏强悬疑线中需极度压缩续场，把思考塞进行动间隙。
3. **四级悬念密度**：宏观悬念（全书生死母题）→ 超级悬念（未知幕后对手）→ 场景悬念（本场怕失去什么）→ 段落悬念（句尾/段尾藏钩与信息迟滞）。
4. **章末「悬崖挂壁（Cliff-Hanger）」隐痕规则**：
   - 章末断在「刀已悬起/反击后果尚待落地/信息差刚刚掀开一角」的一刻，不让读者处于「万事大吉可以安心合书」的状态。
   - 轮换悬崖类型（肉体危局 / 秘密败露倒计时 / 道德两难 / 认知颠覆），避免读者看出作者套路。

## 三、叙事视角零污染纪律（严禁「视角游离」）
在第一人称或有限第三人称单一视角场景内，遵循以下硬约束：
- **禁止跨脑透视（Head-Hopping）**：当前场景锁定角色 A 为 POV 时，**绝对禁止**在同一场景无过渡切入角色 B 的内心独白（「他暗自盘算着……」「她其实早就嫉妒……」）。
- **他者内心外化规则**：非 POV 角色的情绪、犹豫与隐藏动机，只能通过 POV 角色**亲自看见、听见或推断出的外部线索**展现（如指节发白、刻意避开视线、突然打翻茶杯却反常道歉）。
- **视角滤镜一致性**：同一个客观物件（如一把生锈手术刀），医学生 POV 看到的是齿纹损耗与消毒痕，逃犯 POV 看到的是反光与顺手程度；叙述用词必须受当前 POV 见识与立场约束。

## 四、自检清单
- [ ] 本场是否存在清晰的「正负价值偏移」，而非原地说明状况？
- [ ] 对话/搏弈中角色策略是否在节拍推进中真实变化？
- [ ] 全场是否严格锁定单一 POV，没有任何未经转场的他人内心直白？
- [ ] 章末是否留有未释张力、未解风险或可触发下一章抉择的悬崖瞬间？
