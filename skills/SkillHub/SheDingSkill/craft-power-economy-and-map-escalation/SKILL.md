# 大写作手法 · 力量体系、经济生态与换地图防崩盘

## 何时使用与适配题材
- **最佳适配**：玄幻仙侠、西幻蒸汽、都市高武、末世科幻、领主种田基建、长篇多卷升级流。

## 一、力量体系「四件套」设计法（缺一必崩）
任何体系（境界/序列/异能/机甲/金手指）落地前必须填满四格：
1. **核心机制（怎么变强）**：清晰易记的晋升台阶（建议 5–9 大阶），且每升一阶带来**质变新能力**而非纯攻击力 ×10。
2. **硬代价与失控风险**：晋升失败会怎样？超负荷动用会透支寿命、理智、记忆还是引来天劫/污染/组织追杀？
3. **克制链与弱点**：拒绝唯境界论的死板压制，保留「属性相克、情报先手、阵地陷阱、团队配合」越级反杀的空间。
4. **稀缺资源与社会分配**：变强所需的灵石/魔药/芯片/功法由谁垄断？底层如何靠卖命/借贷/站队换取上升通道？（资源稀缺本身就是源源不断的剧情冲突源！）

## 二、力量嵌入社会生态（让世界活起来）
问清三个「现实推演问题」：
- 如果存在读心术/隐身/瞬间移动，当地的**银行、刑侦、贵族安保与婚姻继承**会演化出什么反制手段？
- 超凡者与普通人之间是剥削、庇护、隐秘共生还是契约雇佣关系？
- 货币购买力与阶层鸿沟如何具象化在日常细节里（例如底层修士一辈子攒不够一粒筑基丹/一颗非凡特性）？

## 三、长篇换地图「升维不洗白」三原则
1. **旧战力保值**：新手村天花板去新地图仍是受尊重的中坚或一方诸侯，而非路边扫地杂役；新地图真正可怕的是**更复杂的规则、更庞大的组织资源与信息差**，而不是简单把战力数字多加三个零。
2. **旧人脉带线**：换地图不是断绝过往——带着旧地图的因果债、托付、盟友线索或被旧势力追杀的余波跨界，保持全书一体感。
3. **阶梯式视野打开**：地图切换伴随世界底层真相揭开一层（如从县城争斗 → 州府宗门 → 帝国棋局 → 纪元秘密），让换地图成为「格局跃迁」而非「换皮重练」。

## 绝对禁止项
- 禁止一口气抛出 30 个空洞境界名称和复杂换算公式折磨读者。
- 禁止前卷吹上天的保命底牌到了下一卷突然莫名失效且毫无解释。
- 禁止在最终正文中输出体系设计清单。
