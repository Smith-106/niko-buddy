# niko-buddy 多层知识库分流考据与无痕注入

## 何时使用
当在 `niko-buddy` 创作小说需要查阅**写作技法**、**历史人文民俗素材**、**理工硬核科学设定**或**本书前文设定与状态**时调用本技能。严格遵守「定库再查」「不改 `niko-buddy` 自研主基底」与「先 Wiki 词条、后混合检索」契约。

## 一、WeKnora 三库 + LanceDB + Nowledge Mem 精确分流路由

| 查询诉求 | 唯一目标库 / `kb` 参数 | 推荐检索方式 | 禁止行为 |
|---|---|---|---|
| **本书前文、人物状态、伏笔台账、时间线** | `niko-buddy` 本地 **LanceDB** | 本地向量 + 元数据状态卡直查 | 禁止用外部库替代本书实时状态真源 |
| **小说写作技法（结构/开篇钩子/中段反转/自编辑/冲突悬念/人物心理/对白潜台词/视角/诡计）** | **WeKnora `craft` · 写作技法库**<br>(`b4f22fe9-8581-4a33-9d7e-000000000001`，93 本 / 9,113 条 Wiki) | `search_writing_wiki(kb="craft")` → `read_writing_wiki_page(kb="craft")`；深查原书用例再用 `search_writing_reference(kb="craft")` | 禁止把工程教程或百科设定混查进技法查询 |
| **历史制度、官制礼俗、饮食器物、地理博物、宗教神话、时代生活细节** | **WeKnora `lore` · 小说素材与人文库**<br>(`b4f22fe9-8581-4a33-9d7e-e1461eed5a4b`，1,375 册 / 69,349 条 Wiki，默认) | 先 `search_writing_wiki(kb="lore")` → `read_writing_wiki_page(kb="lore")`；未命中再用 `search_writing_reference(kb="lore")` | 禁止整段粘贴百科条文充作小说描写 |
| **物理化学、医学法医、生物基因、计算机/AI、机械工程与硬科幻/职业考据** | **WeKnora `tech` · 理工与计算机库**<br>(`b4f22fe9-8581-4a33-9d7e-000000000002`，389 册 / 18,835 条 Wiki) | `search_writing_wiki(kb="tech")` → `read_writing_wiki_page(kb="tech")`；查具体参数/反应机理再 `search_writing_reference(kb="tech")` | 禁止靠脑补编造违背基本理化/法医常识的伪参数 |
| **流派规则、标杆拆书先验（诡秘/道诡/凡人等）与创作偏好** | **Nowledge Mem**（静态 Snapshot / Space） | 离线 `NMEM_SNAPSHOT` + 作品 Space 直取 | 禁止将大部头原书考据倒入 Nowledge Mem |

> 跨库检索提示：仅在明确不确定词条归属时使用 `search_writing_wiki(kb="all")`；`search_writing_reference`（向量+BM25+Rerank）只用于单库深查，避免无差别全量扫描。

## 二、考据与技法「防幻觉 + 冰山法则」四步注入法
拿到 WeKnora（`craft` / `lore` / `tech`）结果后，严禁直接把理论条文或百科说明文塞进正文，必须经过四步转化：
1. **核验与边界声明**：命中一手词条或技法原书时保留结论依据；未命中时诚实标记「未查得可靠依据，按架空自洽处理」，禁止编造虚假考据。
2. **只露出 10% 冰山尖**：每查回 1,000 字背景资料，本章正文最多显性呈现 **1–2 个高质感活细节**（具体称谓、手工业工序、伤情反应、协议漏洞），其余 90% 沉在水面下保证逻辑成立。
3. **转译为障碍与感官动作**：
   - 把**`lore` 史料**变成角色脚下的泥泞、衣服上的煤灰与官制卡点；
   - 把**`tech` 理工规律**变成武器射程限制、毒理发作窗口与算力代价；
   - 把**`craft` 技法原则**拆成具体一两场戏的行动—反应节拍（Beat）与视角限制。
4. **回写沉淀边界**：单书新设定的规则落回本书 LanceDB/设定文档；通用文风与创作纪律通过 `SkillHub` 与规则文件固化。

## 三、验收清单
- [ ] 查询前已按「技法 (`craft`) / 人文素材 (`lore`) / 理工 (`tech`)」正确分流。
- [ ] 本章涉及的专业/历史/理化细节均经核验或明确标注为架空自洽设定，无违和硬伤。
- [ ] 正文中无「如你所知」式设定科普段或生硬理论术语，细节已化为道具、动作与阻力。
- [ ] 未破坏本书前文 P0 设定与时间线一致性。
