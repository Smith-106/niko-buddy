# 小说创作引擎核心纪律与知识库规则（写作技法库 + 三层知识架构）

> 本规范为 `niko-buddy`（QMAI）小说创作引擎统一创作规则总纲，结合 `写作技法库`（79 本核心小说创作论著）与项目现有 `P0 > P1 > P2` 门控体系执行。

## 一、WeKnora 三库 + 本地库精确检索规则

| 目标库 | WeKnora `kb` 参数 | 适用范畴 | 禁止事项 |
|---|---|---|---|
| **本地状态库（LanceDB）** | —（内置 Tool） | 本书已定章节、人物实时状态、伏笔台账、时间线 | 禁止用外部参考库覆盖本书既有正史 |
| **写作技法库** | `craft`（79 本 · 7,943 条 Wiki） | 开篇钩子、三幕/LOCK结构、中点与高潮、场景节拍、视角纪律、潜台词、推理公平线索、自编辑改稿与情感张力 | 禁止把理论术语原文照抄成正文旁白 |
| **小说素材与人文库** | `lore`（默认） | 历史官制、地理风物、服饰饮食、民俗宗教、时代生活实貌 | 禁止脱离时代与阶层常识、禁止百度百科式灌输 |
| **理工与计算机库** | `tech` | 理化反应、医学法医、生物基因、计算机与AI、机械工程参数 | 禁止编造违背已知因果与基本量纲的伪科术语 |

- **检索链路顺序**：一律先调用 `search_writing_wiki` → `read_writing_wiki_page`，仅当 Wiki 词条缺失或需原文逐字例证时再调 `search_writing_reference`；库内未命中时如实标记未查得依据，禁止伪造考据。

## 二、创作与审校六条硬核规则（按 `Consistency(P0) > Anti-AI(P1) > Quality(P2)` 裁决）

1. **[P0] 单一视角与信息边界铁律**：
   - 限制性视角下严禁同场景内跨脑窥视（「视角游离」）；非视角人物的内心只能通过外部微动作、停顿、语气与物理证据展现。
   - 反派/伪装者在无人观察的独处场景内，严禁面向「读者」表演假象。
   - 角色只能依据本人在当前时间点已经知情/亲历的信息做判断与下决策。
2. **[P0] 世界观内在同一性与等效代价律**：
   - 架空程度越高，前期确立的力量规则、代价与禁止项越不可破；严禁临时新增免代价外挂解决死局。
   - 公平线索与零巧合：决定性反转所需物证/异兆/规则前提须提前自然进场；有机红鲱鱼必须能被人物副线自洽解释；严禁纯巧合或机械降神破解核心谜团。
3. **[P1] 去 AI 味、潜台词与静态描写熔断**：
   - 严禁抽象套话（如「仿佛时间静止」「嘴角勾起一抹弧度」「一股莫名的寒意」「眼中闪过一丝复杂」等模板味高频词）。
   - 纯静态环境与外貌描写连续不超过 3 句，立刻转化为角色动作、感官摩擦与道具操作（打通听觉/嗅觉/触觉/温差）。
   - 对话不讲明潜台词；角色必须借助试探、绕弯、施压或打岔说话，且每 2–3 轮交锋至少切换一次交流策略。
4. **[P2] 开篇契约与「三重死亡」赌注**：
   - 第一页确立语气与承诺并撕开生活稳态，禁止把百科前史或地形简介堆在开场；每卷/每章核心矛盾必须至少挂钩「肉体 / 社会身份 / 心理信念」之一的高风险赌注。
5. **[P2] 场景价值翻转与节拍推进**：
   - 每一场戏（Scene）必须包含「目标 → 阻碍 → 价值正负翻转/带代价结果」；对话与动作按行动—反应节拍递增张力，严禁功能重复的注水水场。
   - 重大转折前需保持章节呼吸与章末未释张力（`Cliff-Hanger` 隐痕收束），避免连续高强度硬打或情绪平推。
6. **[P2] 冰山 10% 考据注入原则**：
   - 查回的文化与理工细节只取 **1–2 个能卡住行动、弄脏衣物、决定生死的具象实体** 放进当前场景，90% 资料沉底做后台一致性校验，不炫技、不掉书袋。
