# 大写作手法 · 自编辑改稿、删水提纯与句法精修

> 理论溯源：WeKnora `写作技法库`（《来稿恕难录用》《如何写砸一本小说》《Stein on Writing》《Artful Sentences》《小说写作：叙事技巧指南》《修改》）。

## 何时使用与适配阶段
- **核心场景**：初稿完成后的审稿改稿（Review / Rewrite）、压缩冗长水分章节、修正「像 AI 总结/概念解释过多/句式单调」的稿件。
- **硬边界前置**：修改必须严格服从 `Consistency(P0) > Anti-AI(P1) > Quality(P2)`；**严禁**为了句子顺滑或压缩篇幅删掉已埋线索、时间锚点、人物知情限制或物理代价。

## 一、自编辑四重镜头顺序（先大结构，后小文字）
不要在初稿刚写完时一上来就抠形容词——按从大到小的四层顺序下刀：
1. **结构与承重墙审视**：整场戏如果拿掉，对主角目标、阻力或人物关系毫无影响，**整场删除或并入相邻场景**；敢于拆掉看似华丽却拖慢主线的「承重墙」级偏题段落。
2. **场次进出切片（「晚进早出」）**：删掉每场开头的「到场寒暄 / 坐下倒水 / 环境巡检」和结尾的「起身告别 / 回去睡觉」；把入口推迟到冲突触发前半秒，把出口掐在余震最疼的那一句。
3. **Show vs Tell 与过滤词清理**：
   - 斩除所有感官过滤词（例如：「他感到阵阵寒意」「她意识到对方在撒谎」「众人觉得气氛骤然凝重」「眼中闪过一丝复杂」）。
   - 直接写出触发判断的**生理反应 + 外部证据 + 动作后果**：例如用「他捏着茶杯边缘，指节叩了一下瓷面，把杯口朝外转了半寸」替代「他心里开始戒备起来」。
   - 删掉在对话后替读者画蛇添足做阅读理解的解释句。
4. **句法与节奏精修**：
   - 删去「副词拐杖」（如用单音节精准动词替代「狠狠地看了一眼 / 迅速地跑过去」）。
   - **长短句变频**：高烈度动作、博弈交锋用短句断奏加快呼吸；停顿沉思、情绪余韵用层次分明的长句落地；把全句最有分量的信息或反转词放在句尾（End-focus 末尾重音）。

## 二、10%–15% 删水自检清表
改稿后逐项核验：
- [ ] 是否清除了无功能推进的纯说明性倒叙与重复「前情提要」？
- [ ] 是否削掉了同一情绪连用两个同义短句或三连排比的机械「总结腔」？
- [ ] 非必要静态外貌/天气描写是否严格控制在连续不超过 3 句？
- [ ] 对白中每一轮是否去掉了「嗯、啊、对了、话说回来」等注水垫词（除非刻意塑造某角色结巴/拖延的语言癖好）？
- [ ] 所有删改后，时间线、道具持有权、伤口状态、人物知情边界等 **P0 事实是否 100% 完好留存**？

## 三、绝对禁止项
- 禁止用辞藻华丽的空洞比喻掩盖场景逻辑漏洞或动机缺失。
- 禁止把本应留在潜台词里的暗流改写成人物大段自白剖析。
- 禁止在未校验前后章正史的情况下擅自更改设定名词、伤痕位置与时间顺序。
