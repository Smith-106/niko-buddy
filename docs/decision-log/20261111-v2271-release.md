### 节奏豁免（登记早于 tag push）

用 `scripts/check-release-cadence.mjs` 的同源算法（`evaluateTarget`）对真实 release 列表（gh，87 条）按本机时区 +0900 在 2026-11-11 实测：

| 规则 | 实测 | 结论 |
|------|------|------|
| `weekly-stable` | ISO 周 2026-11-09 现有 1 个 stable（v2.27.0@2026-11-09），本版令该周计数 = 2 | **触发** |
| `same-day-duplicate` | 2026-11-11 与前一 stable（2026-11-09）不同日，当日 stable ≤ 1 | 不触发（不登记） |
| `thirty-day-stable` | 2026-10-12 起累计 23 个稳定版；发布前 30 天 stable = 23（上限 4） | **触发** |

因此 `scope` 只登记 `weekly-stable`、`thirty-day-stable` 两项；未触发的 `same-day-duplicate` 不顺手放宽。豁免必须先登记再推 tag：节奏判定发生在 release 存在之后，`exit != 0` 即本次发布作废，无法事后补登。
