# 决策日志：F-001 数据源合规裁定（2026-09）

- **任务**：TASK-011（OpenWrite W5 前置门禁，C-014）
- **证据**：`docs/p4/f001-market-data-sourcing.md`（评估全文、三类标注、排除清单、不做清单）
- **裁定**：**verdict = blocked**。合规可用来源 = 0 → F-001 不进入实施波次；TASK-012 未实现。

## D1 —— 厂商端点全量排除，且排除项不得作为回落

`openxz.cn` 系（含 `pay.` / `newapi.` 子域）、`api.kilo.ai` 系，以及 `api-endpoints.txt` 中的硬编码 IP:port 直连，**一律不得作为数据源**。

**理由**：C-014 的前置约束即「排除全部厂商端点」；硬编码 IP 回落绕过域名与 TLS，来源主体不可识别、许可不可追索，属同等级排除对象。

**后果**：唯一技术上可直接取数的来源被排除 → 门禁的通过条件只能由「平台本体」或「公开许可数据集」满足（见 D2/D3），而二者均未满足。

## D2 —— 平台本体榜单判为「需授权/禁止」，不判「可自持」

起点 / 番茄 / 七猫 / 晋江等平台本体榜单：无公开 API、条款禁止自动化获取 → 分别判 **需授权**（有付费/书面授权路径）或 **禁止**（条款明文禁止）。

**理由**：`api-endpoints.txt` 中出现的 `/api/qidian/ranks`、`/api/qidian/rank_top` 是**厂商侧自行聚合的镜像**，不是平台授权接口。把镜像当成「平台可达」等于把排除对象换个域名继续用。

**判定方向说明**：此处采用保守标注（宁可判「需授权」而非「可自持」）。保守只会更严，不会误放行。

## D3 —— 公开许可数据集的成立条件：许可证 + 字段语义双重满足

第 6 类候选（公开数据集）**仅在**同时满足「明确许可证（CC-BY/CC0 等）」与「覆盖所需字段语义」时才算 **可自持**。本次评估未找到同时满足者 → 不成立。

**后果**：不得以「应该存在某个开放数据集」为由放行。日后再现该类来源须重开本门禁。

## D4 —— 字段覆盖度记为「未评估」，不给凑数覆盖率

卡片要求「≥1 合规来源的实测连通性与 15 字段覆盖度」。无合规来源 → 无测量对象；且字段清单的原始素材 `vocab-hits.txt` 是 456 KB 字符串 dump，**不是稳定字段契约**。从 dump 反推 15 字段等于发明接口（违反 INV-4「不得发明契约/权重」）。

**后果**：`未评估` 是结论的一部分，与 `blocked` 互为因果；不得为凑判据而伪造覆盖率数字。

## D5 —— 门禁通过 = 三元组 + 分层归置 + 永非 canon（预先钉定，本次不实现）

若将来解冻，任何外部数据入库**必须**同时满足：

1. **provenance 三元组** `source` / `captured_at` / `capture_hash` 缺一即**拒绝入库**；
2. **三层归置**（C-006）：原始样本 → `QM/raw/sources/rank/`；规范化摘要 → `QM/book-analysis/`；TTL 内运行缓存 → `.novel/market/`；
3. **分类轴** `external_refetchable`（TASK-001 轴，与 `untrusted_input` 正交），**不入** projection 重建链与 self-heal，`capture_hash` 钉定重建输入；
4. **永不进入 canon 真值链**，与 NB 内生评分不一致时**以内生评分为准**；
5. **注入为最低优先级层**（外部数据 < canon）；
6. **降级链三态** `pending/succeeded/degraded`，`degraded` 永不阻断离线路径；
7. **不做清单**（详见评估文档 §5）七条保持有效，其中第 7 条「不新增可执行通道」与全局硬否决同源。

**理由**：这些约束是本次评估唯一可交付的「设计资产」。先钉定再解冻，避免解冻时因赶工而放宽 provenance 或引入 canon 回写。

## 后果（Consequences）

- **F-001 维持 ABSENT**，0 行采集代码；OpenWrite 12 特征中的 A-F-001 判定不变。
- **TASK-012 未实现**并登记为「门禁未通过」，不计为遗漏；其 7 条收敛判据（含 `market_data.rs`、`MarketDataPanel`、`market-data-client.ts`、`market.*` i18n 键）**无对应产物**，是本波 blocked 的直接体现。
- **硬否决复核增强**：`market_data.rs` 不存在 → 其中 `openxz.cn` / `kilo.ai` 命中恒为 **0**（判据 6 成立）。
- 若后续有人试图「先短暂接入厂商端点跑通再换源」，D1 + 评估文档 §5 第 2 条已明文禁止。

## 未决项（Unresolved）

1. **平台付费接口的实际许可条款**未逐条取得（本环境无外网）→ 「需授权」的准确边界待补。
2. **是否存在带明确许可的网文榜单数据集**未穷举 → 结论是「未找到」而非「不存在」。
3. **15 字段语义清单的权威来源**未定位（`vocab-hits.txt` 非契约）→ 若解冻需先定义字段契约。
4. **门禁重开条件**未写成自动检查 → 目前依赖人工判断「是否出现合规来源」。
