### D1 组合规范化全序（组合顺序稳定的强形式）

- **value**：`combinePacks()` 排序主键 = `GATE_MAPPING[gate].priority` 升序（Consistency(P0) > Anti-AI(P1) > Quality(P2)，CLAUDE.md 硬约束 3）；同优先级 tie-break = ruleId 字典序。**栈元数据（`id`、`packIds`）同样取字典序**，不保留拼接顺序。
- **rationale**：全序保证 `combinePacks(任意排列)` 对**整个栈对象**（含元数据）DeepEqual 同一冻结栈——比"仅规则序列稳定"更强，使下游（T24 packs、未来 digest 缓存键）无需关心拼接顺序。首版曾保留 packIds 拼接顺序留痕，被 fast-check 零规则场景击穿后改为全规范化。
- **evidence_ref**：spec「属性·组合顺序稳定」对 ≤4 包全排列枚举断言；单元用例断言 `packIds` 字典序。

### D2 hardShortCircuit 口径

- **value**：`(gate, verdict) → verdict==="fail" && gate!=="quality"`。即 P0/P1 fail 短路全部后续低优先级门；Quality(P2) fail **永不触发短路**（末端门且不得挡结案）。
- **rationale**：蓝图 F-16 "RuleStack 硬短路（P0>P1>P2）"+ 硬约束 3 "Quality 永不覆盖 Consistency 的失败"；与 control-kernel route() 的 quality=fail→judge 行为同构。

### D3 craft.finale 升格口径

- **value**：`craftFinaleEscalation(findings, isFinale)` 仅当 `isFinale=true` 时把 quality 门 `warning` 升格为 `error` 并标 `escalated:true`；非 quality 门与非 warning 级一律不动。终局判定输入（craft beat_label=`finale/final_image` 或全书末章）由调用方给出，本模块只消费布尔。
- **rationale**：任务原文"终局章才升 quality.warning"。非终局章 quality warning 保持原级（投影 pass），保证 L9 书稿里程碑外的章节不被文学诊断阻断。

### D4 禁动态注册的机械保证

- **value**：`combinePacks()` 产物深度冻结（栈/rules/rule/packIds 全 frozen）；`runRuleStack()` 前置守卫拒绝一切未冻/手搓对象（`RuleStackNotFrozenError`，含品牌位 `kind:"rule-stack"` 校验）。规则运行期只返回 findings，不存在注册通道。**不设 run 后长度复核**——冻结数组上任何增删同步抛 TypeError，复核分支不可达（已删除以免死代码）。
- **rationale**："组合在 run 前冻结，run 内禁动态注册"；防御职责单点化到 freeze + 前置守卫，spec 以 push 抛 TypeError 实证。

### D5 finding 盖章机制

- **value**：规则产出 `RawRuleFinding`（无归属信息）；`runRuleStack()` 运行器统一注入 `ruleId` + `gate` 盖章，并对 severity/message 做机械校验（非法值抛 `RuleStackIntegrityError`）。规则无法谎报归属门。
- **rationale**：gateProjection 按 `finding.gate` 分组过滤，盖章单点化保证分组真源唯一；dimensionId 若提供则组合期经 T22 `getGateForDimension()` 校验与声明 gate 一致（GATE_MAPPING 三门控复用点）。
