| evidence_ref | `src/components/novel/corkboard-view.tsx`、`src/components/novel/plotgrid-view.tsx`、`src/components/review/review-center-view.tsx`（data-storyboard-toggle/panel/tab）；vitest corkboard+plotgrid+review-center 48/48 绿 |

### 设计决策

1. **不建第二份时间线真源**：Corkboard 卡片从 `.novel/snapshots` 只读派生（chapter-ingest 的 `listSnapshots`/`loadSnapshot` —— 与 TimelineView `getTimelineEvents` 同一派生源，ingest 时 `mergeSnapshotTimeline` 亦从快照写入 timeline.json）；Plotgrid 章节列同样来自 `listSnapshots`。零新持久化文件。
2. **G-002 resolution 落地**：不新建独立 plotline 实体 —— 矩阵行复用伏笔池（foreshadowing-tracker 条目），单元格参与标记由 `plantedChapter`/`advancedChapters[]`/`resolvedChapter` 派生（`derivePlotlineParticipation` 纯函数，去重 + 升序）。伏笔池精度有限为已知风险，后续如需独立 plotline 实体再立项。
3. **卡片字段来源**：标题=快照 `chapterTitle`（缺省回退「第N章」）；摘要=快照 `summary`；字数=读 `wiki/chapters/*.md` 按既有 `chapter_number:` frontmatter 约定匹配后用 `countChapterBodyWords` 计数（与 knowledge-tree 同款约定，文件缺失优雅降级为无字数徽标）；情绪标签=emotional-arcs 投影按章去重截断 3 个。
4. **子面板入口**：ReviewCenterView 内部 local state（`storyboardOpen`/`storyboardTab`），右下角悬浮按钮 opt-in，右侧滑出面板含三 tab（卡片墙/情节矩阵/时间线）；不改 wiki-store 的 activeView 联合类型，不影响任何路由分支。
5. **数据刷新**：与 TimelineView 同款 `project`+`dataVersion` 订阅 + cancelled flag 防陈旧请求，ingest bumpDataVersion 后自动重取。

### 设计决策

1. **纯客户端一次性产出**：不调用 streamChat、不走 Draft-first 草稿态、无任何写入路径（grep 验证仅注释提及边界）。产出直接复制到剪贴板，用户自行粘贴到文生图工具。
2. **模板外部化**：JSON 独立于组件维护（Vite 静态 import 打包）；`normalizeCoverPlatforms` 防御性规范化 —— 缺 platform/promptTemplate 的条目丢弃，尺寸非法回退 600×800，空列表渲染降级提示不崩溃。
3. **占位符契约**：`{{platform}}/{{style}}/{{width}}/{{height}}/{{title}}/{{genre}}/{{keywords}}`；ES2020 lib 无 replaceAll，用 split/join reduce 实现。
4. **入口（MAY 项已做）**：icon-sidebar 底部新增 Image 图标按钮 + Dialog 弹出（local state，不新增 activeView，不进主链热路径）；icon-sidebar 既有 spec 全绿无回归。
