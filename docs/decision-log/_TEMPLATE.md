# decision-log 模板（蓝图 §9.7 / A-34，T06 落档）

> **路径约定**：`QMAI/docs/decision-log/YYYYMMDD-<slug>.md`
> **强制规则**：每任务完成定义强制含『decision-log 条目已落』（蓝图 §9.7 + A-34 扩展）；lint 脚本扫『完成任务无 log 条目』校验落档。
> **decision_type 枚举**（§9.7）：`U-xx 定稿` / `基线值` / `统计口径` / `手设参数` / `裁决人` / `外部佐证引用`（§9 扩展）/ `技术债条目`（本文件 §二）

## 一、decision-log 条目模板（常规决策）

| 字段 | 值（填写示例） |
|------|----------------|
| date | YYYY-MM-DD |
| task_id | Txx 或 U-xx 未决项编号 |
| decision_type | 上枚举之一 |
| value | 定稿值 / 基线值 / 口径 / 参数 / 裁决结论（具体到可复核） |
| evidence_ref | `文件:行` / 实测命令输出 / 报告编号 |

## 二、债条目模板（技术债，T06 要求的 描述/偿还触发/到期阶段 三栏）

| 债 ID | 描述 | 偿还触发 | 到期阶段 |
|-------|------|----------|----------|
| DEBT-YYYYMMDD-xx | 现象与产生原因（含引入任务） | 可观测的偿还条件（指标/事件/硬门） | 最迟偿还阶段（如 P1 收口 / T18 前） |

## 三、模板使用说明

1. 每个条目一个表格行；同一文件可含多条条目（决策 + 债）。
2. 债条目到期阶段到期仍未偿还 → 该阶段收口时须显式评审是否延期并更新触发条件，不得静默过期。
3. 首条债条目见 `2026-08-20-t06.md`（T06 先产模板 + 首条债条目，蓝图 §9.7 第 7 条）。
