## F-007: 情绪账本熔断阈值对齐 NovelForge-v5

### 设计决策

1. **NovelForge-v5 源码分析**：`reference/NovelForge-v5/core/emotion_tracker.py` 的 `EmotionalDebtLedger` 使用 `net_debt` 量纲为 0-100+，与 QMAI 的 -1.0~1.0 `netValue` 量纲完全不可比。NovelForge-v5 无显式 Circuit Breaker 阈值，仅有 `_determine_emotional_state()` 状态枚举 (`net_debt > 80` 极度压抑 / `> 50` 压抑 / `> 20` 谨慎 / `> -20` 中性 / `> -50` 乐观 / `> -80` 兴奋 / 其余狂喜)。

2. **阈值保留**：`EMOTION_CB_THRESHOLD = -0.6` 不变，更新注释说明 NovelForge-v5 无直接对照阈值，-0.6 为 QMAI 基于 -1.0~1.0 量纲的经验设定（对应 NovelForge-v5 CAUTIOUS 状态类比）。

3. **A19 合规确认**：`emotionLedgerToContextText` 仍只输出文本化结果，无 LLM 调用（`streamChat`/`invoke` 零命中）。
