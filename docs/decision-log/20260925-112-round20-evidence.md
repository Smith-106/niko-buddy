## 实证

1. **RV-202 wrapper-fail 路径**：r3r4 注入 `fail("r4-reeval",…)` 后经 wrapper →
   `WRAPPER_EXIT=1` + `STEP FAIL: x: exit 1` + `ALL-FAIL`，无 ALL PASS。
2. **RV-204 树哈希拒绝**：`git cat-file -e <tree>^{commit}` →
   `expected commit type, but the object dereferences to tree type`，exit=128。
3. **RV-205 文本机读一致**：dirty tree 下 `FAIL [r1-cleantree]` + `INFO … (superseded by FAIL)`，
   无 `PASS: R1 tree clean` 行；`states=…r1-cleantree:fail`。
4. **RV-203 链序**：`git merge-base --is-ancestor a741863a HEAD` = ANCESTOR（12 链提交全祖先）。
