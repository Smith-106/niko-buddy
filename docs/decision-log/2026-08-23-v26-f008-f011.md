## F-008: 自适应上下文三态策略枚举

| 字段 | 值 |
|------|-----|
| task_id | F-008 |
| decision_type | 手设参数 |
| value | ContextStrategy = 'full' | 'sliding' | 'summary'，默认阈值 full≤50/sliding 50-200/summary>200 |
| evidence_ref | `context-budget.ts:8-51`，实测 7 条 spec 全绿 |

### 设计决策

1. **三态策略作为 adaptiveScale 曲线上层选择器**，先选态再算预算，不替换现有 budget 曲线（已有 500+ 章实测）。
2. **阈值可 novelConfig 覆盖**：`selectContextStrategy(chapterNumber, config?)` 接受 `Partial<ContextStrategyConfig>`。
3. **strategy 字段作为 additive 信息输出**：`computeContextBudget` 返回 `ContextBudget` 新增 `strategy: ContextStrategy` 字段，现有 budget 字段（indexBudget/pageBudget 等）不变。
4. **边界处理**：`undefined/≤0` 返回 `full`；`≤50` 为 full；`50-200` 为 sliding；`>200` 为 summary。

### 测试覆盖

五分支（≤50 full / 50-200 sliding / >200 summary / 自定义阈值覆盖 / 边界 50 与 200）+ undefined/≤0 守卫 + computeContextBudget 集成验证。
