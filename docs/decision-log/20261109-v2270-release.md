## 背景

v2.26.5（2026-11-07）之后主干累积 26 个提交，分两类：

1. **能力补齐**：MCP 一窗口全流程（`auto` 会话档 + 5 个编排工具真正注册）、深章产出落成可采纳草稿并回 `artifactPath`、`pipeline.status` 投影补 5 个字段、普通草稿坞采纳后回填记忆并四态呈现、`workflowMode` 映射真实深度开关。
2. **真机暴露的阻断缺陷**：采纳草稿覆盖既有正式章时抹掉 frontmatter（下游摄取判 `not_chapter`，记忆回填永不成立）、frontmatter 前置脏行被连带删除、容量类 503 一次即失败。

按 `RELEASING.md` 的版本策略（新功能 → minor），取 **2.27.0**，2.26.5 的直接后继，不跳号。

### 节奏豁免（登记早于 tag push）

用 `check-release-cadence.mjs` 的同源算法对真实 release 列表（gh，59 条）按本机时区 +0900 的 2026-11-09 实测：

| 规则 | 实测 | 结论 |
|------|------|------|
| `weekly-stable` | ISO 周 2026-11-09 目前 0 个 stable（上一批在 2026-11-02 周） | 不触发 |
| `same-day-duplicate` | 2026-11-09 当日 0 个 stable | 不触发 |
| `thirty-day-stable` | 发布前 30 天 stable **22** 个（上限 4） | **必然触发** |

因此 `scope` **只登记 `thirty-day-stable`**，不顺手放宽未触发的规则。豁免必须先登记再推 tag：cadence 判定发生在 release 存在之后，`exit != 0` 即本次发布作废，无法事后补登。
